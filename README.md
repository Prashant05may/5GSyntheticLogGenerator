# Synthetic 5G RAN + Core + IMS Observability Dataset

A synthetic multi-layer telecom observability dataset designed for validating monitoring, analytics, KPI computation, alerting, and Root Cause Analysis (RCA) across **5G RAN**, **5G Core**, and **IMS** domains.

The dataset simulates realistic network behavior, performance trends, alarms, failures, and cross-domain fault propagation to support development and testing of observability platforms.

---

## Dataset Overview

| Property           | Value                                          |
| ------------------ | ---------------------------------------------- |
| Observation Window | **2026-07-06 00:00** → **2026-07-09 00:00**    |
| Duration           | **3 Days**                                     |
| Sampling Interval  | **15-minute ROPs**                             |
| Random Seed        | **21**                                         |
| Reproducible       |  Yes (using identical command-line arguments) |

# Dataset Components

## 1. RAN Dataset

Generated using:

```bash
python3 gnb_synth.py \
    --days 3 \
    --cells 6 \
    --seed 21 \
    --fault-rate 0.01 \
    --outdir ./ran
```

* 6 simulated NR cells
* TS 28.552-style PM counters

# Correlation Strategy

Within each layer

* Join events using **trace_id**

Across layers

* Join records using **rop_start**

This enables end-to-end RCA from RAN through Core and IMS.

# Reproducing the Dataset

Generate all datasets in sequence.

```bash
python3 gnb_synth.py \
    --days 3 \
    --cells 6 \
    --seed 21 \
    --fault-rate 0.01 \
    --outdir ./ran

python3 core_synth.py \
    --days 3 \
    --seed 21 \
    --fault-rate 0.03 \
    --gnb-alarms ./ran/alarms.csv \
    --outdir ./core

python3 ims_synth.py \
    --days 3 \
    --seed 21 \
    --core-alarms ./core/alarms.csv \
    --outdir ./ims
```

Using the same seed (`21`) guarantees deterministic output, making the dataset fully reproducible for testing, benchmarking, and validation.
